# Knowledge Base

Notas técnicas, configuraciones y procedimientos construidos desde la operación.

Esta base de conocimiento reúne documentación reutilizable sobre ciberseguridad, infraestructura, automatización e inteligencia artificial. El objetivo es documentar no sólo **qué configurar**, sino también **por qué**, cómo validarlo y qué considerar durante el troubleshooting.

## Áreas

- **Cybersecurity** — monitoreo, detección, SIEM, firewalls, endpoint security y controles.
- **Infrastructure** — redes, sistemas, servicios y plataformas.
- **Automation** — Python, PowerShell, APIs e integración de plataformas.
- **Artificial Intelligence** — fundamentos, LLM y seguridad aplicada a IA.
