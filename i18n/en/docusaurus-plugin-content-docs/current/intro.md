# Knowledge Base

Technical notes, configurations and procedures drawn from hands-on operations.

This knowledge base brings together reusable documentation about cybersecurity, infrastructure, automation and artificial intelligence. The goal is to document not only **what to configure**, but also **why**, how to validate it and what to consider when troubleshooting.

## Areas

- **Cybersecurity** — monitoring, detection, SIEM, firewalls, endpoint security and controls.
- **Infrastructure** — networks, systems, services and platforms.
- **Automation** — Python, PowerShell, APIs and platform integration.
- **Artificial Intelligence** — fundamentals, LLMs and security for AI.
