# Endpoint — template

:::info Draft
Temporary template for endpoint security notes.
:::

## Detection or issue

Describe the initial signal without assuming its cause.

## Evidence

Hash, path, process, user, timestamp and relevant telemetry, always sanitized.

## Analysis

Cross-check sources and reputation when appropriate.

## Response

Actions taken and their justification.

## Closure

Evidence supporting closure or escalation of the case.
